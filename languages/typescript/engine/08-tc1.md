## TC1 step 1 as built: the switch and the interned key (`c2452bb`; reviewed 2026-11-24)

**What it is.** `Precision::{Default, Precise}` (public, `#[non_exhaustive]`, in `calls.rs`), `Options::precision` (`Default` from
`Options::new`), `typescript-cli calls … --precise`. Nothing reads the switch until step 4. `type Key = KeyId`: a `u32` into the request's
`Keys` (`key.rs`, an `indexmap::IndexSet<KeyData>` and a `Vec` of digests at the same places), held by `TypeScript` in a `RefCell` and read
by `Lang::digest`. `KeyData` has no field, so `KeyId::OPEN` (0, digest zeros) is the only key. The six `()` keys of the crate (four in
`walk.rs`, two in `calls.rs`) are `KeyId::OPEN`, or the type `Key`; there was no seventh.

**No engine item is called.** The dependency: `indexmap = "2"`, which tsrs already takes at 2.14.2 with its default features. `Cargo.lock`
gains one line (`"indexmap"` in `typescript-analysis`'s list) and no `tsrs_*` crate is compiled again (coder's report; the lockfile diff
read by the reviewer).

**Reviewer:** 387 pass, 11 ignored (383 + 2 key tests + 2 in `typescript-cli/tests/precise.rs`, which runs six scenarios × four outputs with
and without `--precise`). clippy clean on both crates. Two mutations, both caught: `digest_of` answering ones fails the key test and
`budget.rs`'s no-flag snapshot (the `--graph` output prints the digest); `intern` not pushing a new key's digest fails both key tests.
Depth-1 dumps (`TS_SWEEP_FILE_CODE=1`, dev profile) are equal, graph for graph, to `fbee1b4`'s: V-NOC 1,871, the private codebase
15,575, the TypeScript compiler 12,136. `TaskDetailPanel`'s merged wire and breakdown are byte for byte the same with `--precise`.

## TC1 step 2 as built: a body as plain data, and the gate (`bac93f9`; reviewed 2026-11-24)

**What it is.** `flow.rs` (no engine import): `DefId { program, file, def }`, `Flow { params, sites, anons, unhandled }`, `SiteFlow`,
`Arg`, `AnonFlow`, `Expr::{Unknown, Data, Def, Anon, OneOf}`. `sem/flow.rs`: `Flows` (the program's number from a global counter, the
files as an `IndexSet<P<SourceFile>>`, the memo by `DefId`), `Sem::def_id`, `Sem::func`, `Sem::flow`, and a private `Reader` that reads one
body with one checker handle inside `view::counted`. `Collector` and `Body` list the anonymous functions. Nothing calls `flow` outside
tests yet; the three places that hold it carry `cfg_attr(not(test), allow(dead_code))` until step 4.

**Engine items.** No new engine function. Read through views: `FunctionLike::parameters` (`Node::parameters`, on FunctionDeclaration,
FunctionExpression, ArrowFunction, MethodDeclaration, GetAccessor, SetAccessor, Constructor), `Parameter::is_rest`
(`as_parameter_declaration().dot_dot_dot_token()`), `Conditional::when_true` / `when_false` (the public fields of
`as_conditional_expression()`). Free functions: `ast::is_this_parameter`. The checker, through the existing `functions_named`.

**A hole H17 missed, closed.** `Node::parameter_list` is `self.function_like_data().unwrap()`, and `Node::parameters` calls it: a node that
is not function-like panics. It was not in the ban, which listed the accessors that end in `panic!`. A scan of every `pub fn` of `impl
Node` in `tsrs_ast/src/ast.rs` at the pin for `unwrap`, `expect`, `panic!` or `unreachable!` found 30: 24 already banned, `parameter_list`, and
five that do not depend on a node's kind or that `sem` never calls (`set_flow_node`, `eager_jsdoc`, `as_node`, `original_text`,
`set_jsdoc_cache`). Both are banned now (`clippy.toml`); `collect.rs`'s two calls go through `parameters_of`. An engine bump re-runs the
scan (the command is the one above the downcast list, with `ast.rs` and these words).

**Spellings.** Every `Kind` name of `to_expr`'s data rule is the engine's as the plan wrote it (`PlusToken` … `CaretEqualsToken`,
`InstanceOfKeyword`, `InKeyword`). The private function is `expr_of` (clippy's `wrong_self_convention` refuses a `to_*` taking `&mut self`).

**Reviewer.** 392 pass, 12 ignored; the totality walk meets every kind of the two new views (197,638 nodes, 39 fixture projects); the
table equals `call_sites` on all 865 defs (772 sites) of the fixtures. Mutations: dropping the program check fails the program test;
keeping the `this` parameter fails the parameters test; **taking the outermost anonymous function instead of the innermost fails nothing**
(no fixture has one inside another): a fix adds one. Depth-1 dumps equal to `c2452bb`'s on the three projects.

part; two runs of one part differ by up to a third on this machine (V-NOC's graph: 314 and 209 ms), so read them as ratios, not
milliseconds.
